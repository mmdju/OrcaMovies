# Security Policy

## Reporting a Vulnerability

If you find a security issue related to the Orca Movies bot or this
showcase repository, please report it privately — do NOT open a public
issue.

Report via the [Security tab](../../security/advisories/new)
(Advisories → Report a vulnerability), or contact: **https://github.com/mmdju**

Please include:
- a short description of the issue,
- steps to reproduce it (if possible),
- the date and time you noticed it.

## What to Expect

- Confirmation of receipt within a reasonable time.
- No public disclosure of the details before a fix is available.
- Credit in release notes only if you wish and only with your consent.

## Scope

This policy covers the live Telegram bot described in the README and
the contents of this showcase repository. The bot source code itself
is maintained in a private repository.
